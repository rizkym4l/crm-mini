# crm-mini

Simple CRM with a WhatsApp AI agent for a small shop. A learning project for AI engineering.

The agent chats with buyers, answers product questions from a catalog, takes orders, and hands risky cases to the owner. The owner uses a simple web page to manage orders, customers, products, and chats. It runs locally with Ollama.
